## О проекте

**KFSamara WebApp** — это веб-приложение для доставки еды, разработанное как Telegram WebApp для сервиса **Samara KF**.

Проект реализует весь пользовательский путь: авторизацию через Telegram, выбор товаров, добавление в корзину, оформление заказа, указание адреса доставки, применение промокодов и скидок, а также просмотр статуса заказа.  
Дополнительно предусмотрена административная панель для управления заказами и контентом.

---

## Основной функционал

- Авторизация через Telegram
- Просмотр каталога продуктов и еды
- Добавление товаров в корзину
- Оформление заказа
- Выбор адреса доставки
- Применение промокодов и скидок
- Просмотр статуса заказа
- Административная панель
- Адаптивный интерфейс для мобильных устройств

## Запуск проекта

Проект запускается с помощью Docker.

### Требования
- Docker
- Docker Compose

### Установка и запуск

```bash
git clone https://github.com/your-username/your-repository.git
cd your-repository
docker-compose up --build
```

После запуска приложение будет доступно по адресу, указанному в конфигурации Docker.

## Структура проекта

- **Frontend** — интерфейс пользователя в Telegram WebApp
- **Backend** — обработка заказов, авторизация и бизнес-логика
- **Admin panel** — управление заказами, промокодами и контентом
- **Database** — хранение пользователей, корзин, заказов и скидок
